# Milestone 1 scope

Planned journey:

1. Select a workflow, initially “Implement a Feature.”
2. Answer structured guided questions with static suggestions.
3. Review requirements and unresolved decisions.
4. Generate a reusable prompt set with deterministic predefined templates.
5. Preview, edit, and copy prompts for external tools.
6. Use English or Simplified Chinese on desktop and mobile; select prompt output language independently of UI language.

M1 uses no AI APIs or tokens, authentication, or database. The initialization task implements only the placeholder homepage, language switcher, architecture boundaries, tooling, CI, and documentation. Workflow forms, suggestions, review, generation, editing, and copying remain unimplemented.

Later milestones may explore Supabase, authentication, personalization, prompt history, and AI evaluation, subject to explicit scope decisions.
